# IT-job-analysis-VN
Crawl dữ liệu tuyển dụng IT tại Việt Nam, phân tích xu hướng kỹ năng, mức lương và xây dựng mô hình phân cụm để gợi ý lộ trình nghề nghiệp

# Vietnam IT Job Market Analysis

This project collects job postings from major IT recruitment platforms in Vietnam (ITviec, TopCV, VietnamWorks) and performs data analysis to understand skill trends, salary distribution, and job categories. Machine learning clustering is applied to recommend career learning paths for IT students.

## Features
- Web crawling (Selenium, BeautifulSoup)
- Data cleaning & preprocessing
- Skill extraction & normalization
- Exploratory Data Analysis (EDA)
- K-means job clustering
- Dashboard (Power BI/Tableau)
